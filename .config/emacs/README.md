# Emacs（Neovim ユーザー向け）

この設定は、主に Org mode で文章・メモ・タスクを扱うための Emacs 構成です。Evil mode を有効にしているため、編集の基本は Neovim と同じです。プログラミング用の LSP、Git クライアント、内蔵ターミナルはこの構成には含まれていません。

## 最初に知っておくこと

- `Esc` でノーマルモード、`i` / `a` / `o` などで挿入モードに入ります。`w`、`b`、`dd`、`ciw`、`yy`、`p`、`/`、`n` / `N` なども普段どおり使えます。
- 行番号は相対表示です。`C-u` はスクロールに使えます。
- 変更したファイルは、ウィンドウからフォーカスが外れたときにも自動保存されます。
- `C-g` は多くの操作・ミニバッファ入力をキャンセルします。迷ったら押してください。
- ノーマルモードの `U` は redo です（Neovim の `C-r` 相当）。`C-a` / `C-x` はカーソル位置の数値を増減します。

## カーソル移動

ノーマルモードでは Vim と同じく `h` / `j` / `k` / `l`、`w` / `b`、`0` / `$`、`gg` / `G` を使うのが基本です。挿入モード中、または Evil を外して Emacs 標準操作を使う場合は、次のキーが対応します。

| キー | 動作 |
| --- | --- |
| `C-f` / `C-b` | 1文字先 / 1文字前 |
| `C-n` / `C-p` | 次の行 / 前の行 |
| `C-a` / `C-e` | 行頭 / 行末 |
| `M-f` / `M-b` | 次の単語 / 前の単語 |
| `C-v` / `M-v` | 次ページ / 前ページ |
| `M-<` / `M->` | バッファー先頭 / 末尾 |
| `C-l` | カーソル行が中央になるように再表示 |

`M-` は通常 `Alt`（または `Meta`）です。補完候補を開いている間は、`C-n` / `C-p` が候補の選択に使われることがあります。その場合は矢印キーでも選べます。

## リーダーキー

ノーマル・ビジュアルモードでは `SPC` がリーダーキーです。途中まで入力して少し待つと、which-key が候補を表示します。

| キー | 動作 | Neovim で近いもの |
| --- | --- | --- |
| `SPC f` | ファイルを検索して開く（隠しファイルを含む、`.git` は除外） | Telescope の find files |
| `SPC /` | ripgrep でプロジェクト内を検索 | Telescope live grep |
| `SPC m` | マーク一覧を開く | marks |
| `SPC n` | 現在の表示から検索語に一致しない行を隠す | — |
| `SPC s` | 現在のバッファーのアウトラインへ移動 | symbols / outline |
| `SPC S` | Org 見出しへ移動 | Org outline |
| `SPC u` | redo | `C-r` |
| `SPC SPC` | Emacs コマンドを名前で実行（`M-x`） | `:` |
| `SPC t b` | テーマを再読み込み | — |

## ファイルとバッファー

| キー | 動作 |
| --- | --- |
| `C-s` | 保存（Emacs 標準の `C-x C-s` も利用可） |
| `SPC f` | ファイル名をあいまい検索して開く |
| `C-x b` | 開いているバッファーを切り替える |
| `C-x k` | 現在のバッファーを閉じる |
| `C-x d` | ディレクトリーを開く（Dired） |

ノーマルモードの `C-x` は Vim と同じ「数値を減らす」に割り当てているため、`C-x C-f` は使えません。ファイルを開くときは `SPC f` を使ってください。パスを直接指定したいときは、挿入モードで `C-x C-f`、または `M-x find-file` を使えます。

Dired では `l` または `RET` で開く、`h` / `^` で親ディレクトリーへ移動、`q` で閉じます。

外部のエディターや Git 操作でファイルが変更された場合、開いているファイルバッファーは自動的に再読み込みされます。すぐに手動で読み直すには `M-x revert-buffer RET`（または `SPC SPC revert-buffer RET`）を使います。未保存の変更があると確認を求められるので、必要なら先に保存してください。

## 分割ペイン（ウィンドウ）

Emacs では、一つのフレーム内に分割した領域を「ウィンドウ」と呼びます。Evil のノーマルモードでは Neovim と同様に `C-w` から操作できます。

| キー | 動作 | Neovim で近いもの |
| --- | --- | --- |
| `C-w h` / `C-w j` / `C-w k` / `C-w l` | 左 / 下 / 上 / 右のペインへ移動 | `C-w h` など |
| `C-w w` | 次のペインへ移動 | `C-w w` |
| `C-w s` | 上下に分割 | `:split` |
| `C-w v` | 左右に分割 | `:vsplit` |
| `C-w c` | 現在のペインを閉じる | `:close` |
| `C-w o` | 現在のペイン以外を閉じる | `:only` |

Emacs 標準の操作も使えます。`C-x o` は次のペインへ移動、`C-x 2` は上下分割、`C-x 3` は左右分割、`C-x 0` は現在のペインを閉じる、`C-x 1` は他のペインを閉じます。直前の分割状態に戻したいときは `C-c <left>`、やり直しは `C-c <right>` です。

## 補完・検索

- 補完候補は入力中に自動表示されます。`RET` で選択中の候補を確定します。
- ファイル名補完と、バッファー内の単語補完が使えます。
- バッファー内検索は Evil の `/`、次/前の一致へは `n` / `N` を使います。
- `C-s` はこの設定では保存に割り当てているため、Emacs 標準のインクリメンタル検索には使いません。横断検索には `SPC /` を使ってください。

## Org mode

`.org` を開くと Org mode と Evil Org が有効になります。文章は画面端で折り返され、行番号は表示されません。

| キー | 動作 |
| --- | --- |
| `TAB` | 見出しやブロックを開閉 |
| `SPC o t` | TODO 状態を切り替え |
| `SPC o c` | チェックボックスを切り替え |
| `SPC o l` | リンクを挿入 |
| `SPC o o` | カーソル位置のリンクを開く |
| `SPC o i` | インライン画像の表示を切り替え |
| `C-c c` | capture（Todo / Note / Journal） |
| `C-c j` | `~/org/journal.org` の当日 Diary を開く・作成 |

Org の短いブロックは、行頭で `<q` と入力して `TAB` のように `org-tempo` のテンプレートも使えます。

## 見た目

編集領域の背景だけが 82% の不透明度で透過します。上部のネイティブメニューバーは無効化済みです。必要になった場合は `M-x menu-bar-mode` で一時的に戻せます。

画面上部のバッファータブは、Neovim の bufferline 風に表示します。選択中のバッファーは明るい紫、他のバッファーは控えめな色で表示されます。タブ名はバッファー名のみを最大 24 文字で表示します。

## 困ったとき

- `C-h k` の後にキーを押すと、そのキーの説明を表示します。
- `C-h f` は Emacs コマンド、`C-h v` は設定変数の説明です。
- `M-x` または `SPC SPC` からコマンド名を検索できます。
